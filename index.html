Architecture & benchmarks Close
  • Stateful LangGraph agent graph. Research Agent (Tavily web search + EDGAR financials) → Filing RAG Agent (SEC 10-K via ChromaDB similarity retrieval) → Risk Assessment Agent (LLM extraction + severity scoring) → conditional edge back to research when risk score > 0.7 and iterations < 3 → Synthesis Agent with Pydantic schema enforcement.
  • Retrieval was tuned by benchmark, not by feel. Switching from MMR to plain similarity search at k=8 lifted company precision 0.82 → 1.00 and keyword recall 0.61 → ~0.79.
  • Every LLM call is observable. Langfuse tracing captures token usage, latency, and risk score per inference.
  • Dates cannot be hallucinated. Each report is stamped with the actual SEC filing date, with a safety net that overrides any model-invented date.
  • Provider-proof. System-message normalization keeps the pipeline alive on LLM providers that reject the system role. 42 network-free unit tests.
Honest limits: the golden eval set is only 10 questions; precision@8 varies 0.975–1.00 run to run because ChromaDB HNSW is approximate; exact financial figures come from EDGAR XBRL rather than the RAG path; free OpenRouter models cap around 50 requests/day.

Healthcare Claims Cost Intelligence

5-tier cost prediction · SHAP explanations · leakage fixed

5 bugs fixed

Predicts the cost tier and total charge of a Medicare-style claim with SHAP explanations behind every prediction. Started as an academic R and Jupyter analysis; rebuilt from scratch as a production Python system — which is how five real methodology bugs surfaced.

The five bugs Close
  • Beneficiary-level train/test leakage. The same patient appeared on both sides of the split — 75% of beneficiaries leaked. Fixed with GroupShuffleSplit on beneficiary ID.
  • Encoders fit before splitting leaked test-set distribution into training. Now fit on the training fold only.
  • Ambiguous state codes. Two redundant state columns existed; the governing rule is now explicit and schema-enforced.
  • Incomplete one-hot encoding of a binary flag, with no path for unseen categories at inference. Fixed with OneHotEncoder(handle_unknown="ignore").
  • An entire state vanished. Wyoming was silently dropped by the original R script because its income was the string "$60,510 ", which parsed to NA. All 51 states and 46,059 rows are back.
  • Scored on a genuinely disjoint test set: 13,288 rows / 1,625 beneficiaries with zero overlap against 32,771 training rows, tuned with RandomizedSearchCV over grouped cross-validation. 51 tests, including mutation-checked leakage regression tests — so the original bug cannot come back quietly.
Hosting, precisely: the Streamlit dashboard is publicly hosted and scores claims in-process from the committed model. The FastAPI service is fully built, Dockerized, and tested, but runs locally via Docker Compose — there is no public API URL.

04 — Rebuild

Retail Demand Forecasting

1M+ rows of IRI point-of-sale data, 2018–2022 · temporal split

Leakage removed

Predicts non-promoted unit sales for the refrigerated tablespreads category. The original capstone reported R² 0.81 while training on columns that were arithmetic components of the target. Thirteen leakage columns removed and a temporal split later, the honest holdout is R² 0.635.

Statistical rigor Close
  • The CV/holdout gap is the finding. Cross-validation on corrected features still reports 0.908 against a 0.635 holdout — temporal and product-region memorization that a random split never exposes.
  • Multicollinearity checked with VIF (max 2.51, well under the threshold of 10).
  • Multiple-comparison correction (Bonferroni, Benjamini-Hochberg) applied to pairwise year comparisons.
  • Residual diagnostics report heteroscedasticity (spread 33× wider in the top vs. bottom fitted quintile) and non-normal residuals — measured and disclosed, not assumed away.
  • Training never hard-depends on the orchestrator: a direct-call fallback keeps the pipeline runnable when ZenML is unavailable. 16 tests.
